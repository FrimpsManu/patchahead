An upstream API changes. Which of your code breaks, what is the smallest correct fix, and can it be proven to work? PatchAhead reads the release note, finds the affected call sites, patches a throwaway copy of the repository, and runs your tests against it. A migration counts as done only when a test that failed before the patch passes after it.

PatchAhead never writes to the repository it is pointed at. Run copies it to a temporary directory, patches the copy, and runs its test command there. A test command is ordinary code running as you — the copy is isolation from writes, not a sandbox. Nothing here is applied or merged; a human approves.
